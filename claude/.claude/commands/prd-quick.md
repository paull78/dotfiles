# Quick PRD Generator (MVP Focus)

Create a lean, startup-style PRD for: $ARGUMENTS

## Lean PRD Template:

### Problem Statement
- What problem are we solving?
- Who has this problem?
- How are they solving it today?

### Solution Overview
- What are we building?
- Why is our solution better?
- What's the core value proposition?

### Target Users
- Primary user persona
- User needs and pain points
- User journey (happy path)

### Core Features (MVP)
- Must-have features (P0)
- Should-have features (P1)
- Could-have features (P2)
- Won't-have features (this release)

### Success Metrics
- Primary metric (North Star)
- Secondary metrics
- How will we measure success?

### Technical Considerations
- Key technical requirements
- Integration points
- Performance targets
- Security requirements

### Timeline & Resources
- Target launch date
- Team composition
- Key milestones
- Dependencies and blockers

### Open Questions
- What don't we know yet?
- What needs validation?
- What research is needed?

Generate a concise, actionable PRD focused on getting to market quickly while maintaining quality.

# Product Requirements Document Generator

Create a comprehensive PRD for: $ARGUMENTS

## File Organization:
Create the following files in the current directory:
1. **PRD-[product-name].md** - Main requirements document
2. **[product-name]-user-stories.md** - Detailed user stories and acceptance criteria
3. **[product-name]-requirements-matrix.md** - Requirements tracking table

## Process:
1. **Discovery Phase**:
   - Ask clarifying questions about the product
   - Understand target users and market
   - Identify key stakeholders

2. **Document Structure** (for main PRD file):
   - Executive Summary
   - Product Vision & Strategy
   - User Research & Personas
   - Feature Requirements (MoSCoW prioritization)
   - Technical Requirements
   - Success Metrics & Analytics
   - Go-to-Market Considerations
   - Resource Requirements
   - Timeline & Roadmap

3. **Deliverables**:
   - Main PRD document (markdown with clear sections)
   - Requirements traceability matrix (table format)
   - User story backlog (with story points)
   - Acceptance criteria checklist

## File Naming Convention:
Use kebab-case and include the product name:
- `PRD-mobile-task-manager.md`
- `mobile-task-manager-user-stories.md`  
- `mobile-task-manager-requirements-matrix.md`

Create structured documents with tables, clear formatting, and sections for stakeholder review and approval.
